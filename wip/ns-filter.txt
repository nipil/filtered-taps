# # 13. Network configuration to set inside Debian
# #
# # Conceptual example:
# #
# #   IP      : 192.0.3.2/30
# #   Gateway : 192.0.3.1
# #
# # The VM must therefore send its traffic through:
# #
# #   Debian 192.0.3.2
# #          |
# #          v
# #   tap0 / sandbox 192.0.3.1
# #          |
# #          v
# #   veth-sandbox 192.0.2.2
# #          |
# #          v
# #   veth-host 192.0.2.1
# #          |
# #          v
# #   host NAT
# #          |
# #          v
# #   wlp2s0
# #          |
# #          v
# #       Internet
